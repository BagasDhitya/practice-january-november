Section wajib di Profile Website:

1. Hero/intro -> siapa kamu + value utama (1 kalimat yang jelas)
2. About -> cerita singkat, fokus ke apa yang kamu kerjakan dan kenapa relevan
3. Services/skills -> daftar layanan/keahlian kamu
4. Portofolio/Project -> contoh hasil kerja (link + description singkat)
5. Experience/Client -> pengalaman kerja, klien, atau achievement penting
6. Testimonial Client -> kutipan singkat dari klien/user
7. Contact -> cara hubungi kamu + ajakan jelas ("Hire me", "contact me")
